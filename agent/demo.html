Overview

This project automates the entire workflow of creating daily YouTube news videos—from fetching breaking news to generating the final video. Inspired by successful geopolitical commentary channels like @ltshijie (381K followers), this system reduces manual work from hours to minutes while maintaining high-quality output.

Key Features

  • Real-time News Aggregation: Automatically fetches latest articles from The Economist with full content extraction
  • AI Script Generation: Uses local LLM (Ollama/llama3.2) to create detailed 2-3 minute scripts with specific facts and quotes
  • Chinese Translation: Automatic translation for Chinese-speaking audience
  • Smart Image Selection: Downloads 8-10 relevant stock photos from Pixabay based on content keywords
  • Video Synthesis: Combines images and voiceover into professional slideshow video
  • Social Media Ready: Generates Twitter preview text in Chinese for promotion

Technical Architecture

News Aggregation Pipeline

The system fetches headlines from The Economist's RSS feed, filters for China/US/Europe keywords, and extracts full article content—not just headlines. This ensures the generated scripts contain specific facts, numbers, and quotes rather than generic commentary.

AI Script Generation

Using Ollama (llama3.2) running locally, the system generates structured video scripts following a proven format:

  • Hook (10 seconds): Most important/surprising development
  • Main Stories (2 minutes): 3-4 stories with specific details
  • Closing (20 seconds): Connect themes and implications

Image Intelligence

Keywords are automatically extracted from the Chinese script using the LLM, then matched against Pixabay's free stock photo library. All images are licensed for commercial use with no attribution required.

Video Synthesis

FFmpeg combines images into a slideshow, automatically calculating display duration per image to match voiceover length. The output is a 720p MP4 video ready for YouTube upload.
