Pytorch case study - Kmeans clustering algorithm per Lloyd method¶

Lloyd method means following two steps within each iteration, akin to EM but not probabilistic.¶

Init X: generate N 2D random data¶

Init C: Choose K out of N points as init centroids¶

selecting K out of N -> X[randperm(N)[:K], :]

For each iteration:¶

step-1: assign each point in X to closest centroid in C.

>> point-wise dist: (N,2) vs (K,2) -> broadcast -> (N,K,2)
>> squared sum over last dim -> (N,K)
>> argmin over K
>> one-hot assignment matrix (N,K)

step-2: recompute C

>> one-hot (N,K), X (N,2)
>> sum of points per cluster: one_hot.T @ X -> (K,2)
>> num of points per cluster: one_hot.sum(dim=0) -> (K)
>> divide with broadcasting -> new C (K,2)

Core Python / PyTorch concepts tested here:¶

1. Broadcasting / indexing
>> same dim, right to left, either match or 1.
>> [, None,] means unsqueeze or exp_dim in TF.
2. vectorizing whenever possible
>> ((a-b)**2).sum(dim=-1) is euclidian point-wise distance
3. make one-hot matrix or mask
4. Linear algebra as aggregation = “multiply to select, sum to aggregate.”

from IPython.display import clear_output

N = 100000
D = 2
K = 10
# init x
x = torch.randn(N, D)
# init c
ind = torch.randperm(N)[:K]
c = x[ind]

iterations = 20

for i in range(iterations):
    # assign each point in X to closeest centroid in C.
    ## point-wise dist
    dist = (x[:,None,:] - c[None,:,:]) # N,1,K - [1,K,2] -> N,K,2
    dist = (dist**2).sum(dim=-1) # N,k or sum of square
    ## argmin
    kernel_assignment = torch.argmin(dist, dim=1) # N,
    ## one_hot # N,k
    one_hot = torch.zeros(N,K)
    one_hot.scatter_(dim = 1, index = kernel_assignment[:,None], value = 1) # N,k scatter per N,1 -> N,k

    # recompute c
    sum_of_points_per_kernel = one_hot.T @ x  # K,N * N, 2 -> K, 2    
    num_of_points_per_kernel =  one_hot.T.sum(dim=1) # K,
    
    c = sum_of_points_per_kernel / num_of_points_per_kernel[:,None] # k,2 / k,1 -> k,2


    # plot
    plot(x,c,kernel_assignment)

def plot(x,c,kernel_assignment):
    clear_output(wait=True)

    X_cpu = x.detach().cpu()
    C_cpu = c.detach().cpu()
    labels_cpu = kernel_assignment.detach().cpu()

    plt.figure(figsize=(5, 5))
    plt.scatter(
        X_cpu[:, 0],
        X_cpu[:, 1],
        c=labels_cpu,
        cmap="tab10",
        s=5,
        alpha=0.6
    )
    plt.scatter(
        C_cpu[:, 0],
        C_cpu[:, 1],
        c="black",
        s=150,
        marker="X"
    )

    plt.title(f"K-means Iteration {i+1}")
    plt.axis("equal")
    plt.show()
