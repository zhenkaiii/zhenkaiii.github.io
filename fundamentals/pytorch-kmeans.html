K-Means Clustering (Lloyd's Algorithm)

PyTorch Drill ~10 min

The Algorithm in 30 Seconds

K-means is Lloyd's algorithm: two steps, iterated. That's it.

  • Init: Generate N data points in 2D. Pick K prototypes by randomly sampling from the data.
  • Step 1 — Assign (O(NK)): For each data point, compute distance to all K prototypes. Take argmin. No sorting — just one pass over K per point.
  • Step 2 — Update (O(N)): For each prototype, recompute its coordinates as the mean of its assigned points. Each point belongs to exactly one cluster, so total work is O(N).
  • Iterate 10–20 times. Total: O(NKI) — all linear factors.

Setup

import torch

N = 1000
K = 8
data = torch.randn(N, 2)                    # N random 2D points
prototypes = data[torch.randint(0, N, (K,))] # K randomly sampled from data
Why sample from data? Guarantees each prototype starts near actual data. randperm(N)[:K] avoids duplicates but randint is fine for a drill.

Broadcasting Rule (the shared foundation)

Both assign and update rely on broadcasting. One rule:

Compare dims right to left. Each pair must be equal or one must be 1.

Missing dims on the left are auto-padded as 1. Missing dims on the right are not — you must unsqueeze explicitly.

# Auto-pads left — works:
(4, 3) + (3,)             # (3,) -> (1,3) -> broadcasts to (4,3)

# Must unsqueeze right — won't auto-pad:
(K, 2) / (K,)             # FAILS — rightmost 2 vs K, no match
(K, 2) / (K, 1)           # OK    — unsqueeze(1) fixes it

Core Loop

Prompt 10 min
Implement the full K-means loop from scratch using only torch ops.
• Broadcasting for pairwise distance — no Python loops over N
• No sklearn, no torch.cdist

Step 1 — Assign (O(NK))

# Broadcasting: (N,1,2) - (1,K,2) -> (N,K,2)
diff = data.unsqueeze(1) - prototypes.unsqueeze(0)
dist = (diff ** 2).sum(dim=-1)       # (N, K) — no keepdim, not broadcasting back
assign = dist.argmin(dim=1)          # (N,)

Step 2 — Update (O(N))

Approach A — Boolean mask (simpler, uses a for-loop over K):

for j in range(K):
    prototypes[j] = data[assign == j].mean(dim=0)

Approach B — One-hot matmul (fully vectorized). The one-hot matrix is the grouping mechanism: matmul does in-group sum in one shot, then divide by group size.

one_hot = torch.zeros(N, K)
one_hot[torch.arange(N), assign] = 1.0   # (N, K) — row i, col assign[i] = 1

sums   = one_hot.T @ data                # (K,N) @ (N,2) -> (K,2) in-group sum
counts = one_hot.sum(dim=0)              # (K,)
prototypes = sums / counts.unsqueeze(1)  # (K,2) / (K,1) — unsqueeze needed on right
