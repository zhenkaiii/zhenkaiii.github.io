The core pattern

A hash map gives O(1) lookup. In interviews, this means: trade space for time — build a lookup structure so you avoid nested loops.

The single most important rule across all hashmap problems:

Check complement first.  Insert afterwards.

In Two Sum: check if target - x is in the map, then insert x. In Subarray Sum: check if prefix - k is in the map, then insert the prefix. Same pattern.

Problem 1: Two Sum (LC 1)

Problem: Given an array nums and an integer target, return the indices of two numbers that sum to target.
Pattern: Complement lookup — for each element, check if its complement exists in the map.
Example: [2,7,11,15], target=9 → [0,1]
Time: O(n)   Space: O(n) 
def two_sum(nums, target):
    seen = {}                          # value → index
    for i, x in enumerate(nums):
        complement = target - x
        if complement in seen:         # check complement FIRST
            return [seen[complement], i]
        seen[x] = i                    # insert AFTERWARDS

Trace: [2,7,11,15], target=9

x=2: comp=7, 7 in {}? no.       seen={2:0}
x=7: comp=2, 2 in {2:0}? yes!   return [0, 1] ✓

Why insert after checking? If you insert first, an element could match itself. Check first, insert after — this guarantees you only find pairs of distinct elements.

Problem 2: Group Anagrams (LC 49)

Problem: Given a list of strings, group the anagrams together.
Pattern: Choose a canonical form as the hash key — sorted characters.
Example: ["eat","tea","tan","ate","nat","bat"] → [["eat","tea","ate"],["tan","nat"],["bat"]]
Time: O(n · k log k) where k = max string length   Space: O(n · k) 
def group_anagrams(words):
    hm = {}
    for w in words:
        key = "".join(sorted(w))       # canonical form: sorted chars
        if key in hm:
            hm[key].append(w)
        else:
            hm[key] = [w]

    return list(hm.values())

Trace: ["eat","tea","tan","ate","nat","bat"]

"eat" → key="aet"  hm={"aet":["eat"]}
"tea" → key="aet"  hm={"aet":["eat","tea"]}
"tan" → key="ant"  hm={"aet":["eat","tea"], "ant":["tan"]}
"ate" → key="aet"  hm={"aet":["eat","tea","ate"], "ant":["tan"]}
"nat" → key="ant"  hm={"aet":["eat","tea","ate"], "ant":["tan","nat"]}
"bat" → key="abt"  hm={..., "abt":["bat"]}
return [["eat","tea","ate"], ["tan","nat"], ["bat"]] ✓

The key insight: same characters in different order → same sorted string. Sorting is the canonical form. For anagrams, that's all you need.

Prefix sum: the building block

A prefix sum is a running total. prefix[j] = sum of all elements from index 0 to j.

nums   = [1, 2, 3, 4]
prefix = [1, 3, 6, 10]     # prefix[0]=1, prefix[1]=1+2=3, prefix[2]=1+2+3=6, ...

The power: any subarray sum is just a subtraction of two prefixes.

sum(i..j) = prefix[j] - prefix[i-1]

# Example: sum of nums[1..2] = nums[1] + nums[2] = 2 + 3 = 5
#          prefix[2] - prefix[0] = 6 - 1 = 5  ✓

This turns "find a subarray with sum k" into "find two prefix sums whose difference is k" — which is Two Sum.

Problem 3: Subarray Sum Equals K (LC 560)

Problem: Given an integer array nums and an integer k, return the count of subarrays whose sum equals k.
Pattern: Prefix sum + hashmap. This is Two Sum in disguise.
Example: [1,2,3], k=3 → 2 (subarrays [1,2] and [3])
Time: O(n)   Space: O(n)

The connection to Two Sum: a subarray sums to k iff prefix[j] - k exists as some earlier prefix sum. That's a complement lookup — same as Two Sum!

def subarray_sum(nums, k):
    running_sum = 0
    hm = {0: 1}                        # prefix sum of 0 seen once ("starting from -1!")
    ans = 0

    for x in nums:
        running_sum += x               # build prefix sum

        if running_sum - k in hm:      # like two sum: search complement in hm!
            ans += hm[running_sum - k]  # there are this many earlier prefixes that work

        hm[running_sum] = hm.get(running_sum, 0) + 1   # insert AFTERWARDS

    return ans

Why {0: 1}?

It means: "a prefix sum of 0 has been seen once — the empty prefix before index 0." Without it, you miss subarrays that start at the beginning of the array. If running_sum == k, then running_sum - k == 0, and you need 0 to be in the map.

Trace: [1,2,3], k=3

init: running_sum=0, hm={0:1}, ans=0

x=1: running_sum=1.  comp=1-3=-2. -2 in hm? no.            hm={0:1, 1:1}  ans=0
x=2: running_sum=3.  comp=3-3=0.   0 in hm? yes! ans += 1. hm={0:1, 1:1, 3:1}  ans=1
x=3: running_sum=6.  comp=6-3=3.   3 in hm? yes! ans += 1. hm={0:1, 1:1, 3:1, 6:1}  ans=2
return 2 ✓

subarray [1,2] = 3 (found at x=2, prefix 3 - prefix 0 = 3)
subarray [3]   = 3 (found at x=3, prefix 6 - prefix 3 = 3)

HashMap cheat sheet

# Basic ops
hm = {}
hm[key] = val                      # insert / update
if key in hm:                      # check existence
val = hm.get(key, default)         # get with fallback

# Counting idiom
hm[x] = hm.get(x, 0) + 1          # increment count

# collections shortcuts
from collections import Counter, defaultdict

freq = Counter([1,1,2,3,3,3])      # Counter({3:3, 1:2, 2:1})
freq.most_common(2)                # [(3,3), (1,2)]
freq['missing']                    # 0 (not KeyError)

groups = defaultdict(list)
groups[key].append(val)             # no need to check if key exists
