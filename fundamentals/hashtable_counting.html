Hash Table & Counting

The Core Idea

A hash table gives O(1) average lookup, insertion, and deletion. In coding interviews, this translates to one dominant pattern: trade space for time — build a lookup structure so you avoid nested loops.

Pattern 1: Complement Lookup (Two Sum)

Instead of checking every pair in O(n²), store seen values and check for complements: 

def two_sum(nums, target):
    seen = {}  # value -> index
    for i, x in enumerate(nums):
        complement = target - x
        if complement in seen:
            return [seen[complement], i]
        seen[x] = i

This generalizes: any time you need to find a pair satisfying f(a, b) = target where f is invertible, consider a hash lookup.

Pattern 2: Frequency Counting with Counter

collections.Counter builds a frequency map in one line: 

from collections import Counter

freq = Counter("abracadabra")
# Counter({'a': 5, 'b': 2, 'r': 2, 'c': 1, 'd': 1})

freq.most_common(2)    # [('a', 5), ('b', 2)]
freq['z']              # 0  (missing keys return 0)

Counter supports arithmetic: 

c1 = Counter("aab")
c2 = Counter("ab")
c1 - c2   # Counter({'a': 1})  — subtract counts, drop non-positive
c1 & c2   # Counter({'a': 1, 'b': 1})  — element-wise min

Pattern 3: Anagram Detection

Two strings are anagrams iff they have the same character frequencies. For sliding-window anagram search, maintain a Counter of the window and compare: 

def find_anagrams(s, p):
    from collections import Counter
    target = Counter(p)
    window = Counter(s[:len(p)])
    result = []

    if window == target:
        result.append(0)

    for i in range(len(p), len(s)):
        window[s[i]] += 1                   # add right
        left = s[i - len(p)]
        window[left] -= 1                   # remove left
        if window[left] == 0:
            del window[left]
        if window == target:
            result.append(i - len(p) + 1)

    return result

Pattern 4: Group-By with defaultdict

defaultdict(list) lets you group items by a computed key without checking for existence: 

from collections import defaultdict

def group_anagrams(strs):
    groups = defaultdict(list)
    for s in strs:
        key = tuple(sorted(s))   # canonical form
        groups[key].append(s)
    return list(groups.values())

# group_anagrams(["eat","tea","tan","ate","nat","bat"])
# [['eat','tea','ate'], ['tan','nat'], ['bat']]

The key insight: choose a canonical form that maps equivalent items to the same key. For anagrams it's sorted characters. For isomorphic strings it could be a pattern like "0.1.2.1".

Pattern 5: Prefix Sum + Hash Map (Subarray Sum Equals K)

To count subarrays with sum k, store prefix sums in a hash map. A subarray [i+1..j] has sum k iff prefix[j] - prefix[i] = k: 

def subarray_sum(nums, k):
    count = 0
    prefix = 0
    seen = {0: 1}  # prefix_sum -> how many times we've seen it

    for x in nums:
        prefix += x
        count += seen.get(prefix - k, 0)
        seen[prefix] = seen.get(prefix, 0) + 1

    return count

Complexity Reminder

Operation Average Worst
Lookup / Insert / Delete O(1) O(n)
Iteration O(n) O(n)

Worst-case O(n) happens with hash collisions. In interviews, assume average case unless asked. Python dicts use open addressing with perturbation; set and dict are both hash tables.
