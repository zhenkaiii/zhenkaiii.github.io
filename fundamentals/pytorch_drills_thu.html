Session 3: K-Means from Scratch ~90 min

The goal: implement K-means clustering using only PyTorch tensor ops. No sklearn, no loops over data points. This drills cdist, argmin, scatter/index masking, and in-place accumulation.

Prompt 1 8 min
Implement my_cdist(A, B) that computes pairwise L2 distances.

Requirements:
• A: (N, D), B: (M, D)
• Return: (N, M) where [i, j] = ||A[i] - B[j]||_2
• No loops. Use the expansion trick: ||a-b||^2 = ||a||^2 + ||b||^2 - 2*a.b
• Verify: torch.allclose(my_cdist(A, B), torch.cdist(A, B), atol=1e-4)

What you need to know

  • Expansion trick avoids materializing an (N, M, D) difference tensor.
  • ||a||^2 = (A ** 2).sum(dim=-1), keep shape for broadcasting.
  • Cross-term: A @ B.T gives (N, M).
  • .clamp(min=0) before .sqrt() — floating point can give tiny negatives.
Show solution after attempting 
def my_cdist(A, B):
    # A: (N, D), B: (M, D) → (N, M)
    a_sq = (A ** 2).sum(dim=-1, keepdim=True)   # (N, 1)
    b_sq = (B ** 2).sum(dim=-1, keepdim=True)   # (M, 1)
    cross = A @ B.T                               # (N, M)
    dist_sq = a_sq + b_sq.T - 2 * cross           # (N, M)
    return dist_sq.clamp(min=0).sqrt()


# Verify
A = torch.randn(100, 64)
B = torch.randn(10, 64)
assert torch.allclose(my_cdist(A, B), torch.cdist(A, B), atol=1e-4)
print("cdist: PASS")
Prompt 2 20 min
Implement K-means clustering: kmeans(data, K, n_iter=20).

Requirements:
• data: (N, D)
• Initialize centroids by randomly picking K data points (no randperm — use torch.randint or randperm, your choice)
• Each iteration: (1) assign each point to nearest centroid, (2) recompute centroids as mean of assigned points
• No loops over data points — only loop over iterations.
• Use torch.cdist (or your my_cdist) for distances.
• Return: (centroids, assignments) — centroids (K, D), assignments (N,)

What you need to know

  • Assign step: dists = torch.cdist(data, centroids) → (N, K), then assignments = dists.argmin(dim=1).
  • Update step: For each cluster k, new centroid = mean of all points assigned to k.
  • The tricky part: computing cluster means without a for-loop over K. Two options:
    • scatter_add + count: accumulate sums per cluster, then divide.
    • Boolean mask per cluster: data[assignments == k].mean(0) — this loops over K (simpler, acceptable for interview).
Show solution after attempting 
def kmeans(data, K, n_iter=20):
    N, D = data.shape

    # Initialize: pick K random data points
    idx = torch.randperm(N)[:K]
    centroids = data[idx].clone()                  # (K, D)

    for i in range(n_iter):
        # 1. Assign: nearest centroid for each point
        dists = torch.cdist(data, centroids)       # (N, K)
        assignments = dists.argmin(dim=1)          # (N,)

        # 2. Update: mean of each cluster
        new_centroids = torch.zeros_like(centroids)
        for k in range(K):
            mask = assignments == k
            if mask.sum() > 0:
                new_centroids[k] = data[mask].mean(dim=0)
            else:
                new_centroids[k] = centroids[k]    # keep dead centroid
        centroids = new_centroids

    return centroids, assignments

Scatter-based (loop-free update):
# Fully vectorized update (advanced — bonus points in interview)
def kmeans_vectorized(data, K, n_iter=20):
    N, D = data.shape
    idx = torch.randperm(N)[:K]
    centroids = data[idx].clone()

    for _ in range(n_iter):
        dists = torch.cdist(data, centroids)
        assignments = dists.argmin(dim=1)            # (N,)

        # scatter_add: sum all points per cluster
        sums = torch.zeros(K, D)
        sums.scatter_add_(0, assignments.unsqueeze(1).expand(-1, D), data)
        counts = torch.zeros(K)
        counts.scatter_add_(0, assignments, torch.ones(N))

        # Avoid division by zero for empty clusters
        mask = counts > 0
        centroids[mask] = sums[mask] / counts[mask].unsqueeze(1)

    return centroids, assignments

Implement cosine similarity from scratch: my_cosine_sim(A, B).

Requirements:
• A: (N, D), B: (M, D)
• Return: (N, M) where [i, j] = A[i] . B[j] / (||A[i]|| * ||B[j]||)
• Handle the zero-norm edge case (use eps=1e-8).
• Verify: torch.allclose(my_cosine_sim(A, B), F.cosine_similarity(A.unsqueeze(1), B.unsqueeze(0), dim=-1), atol=1e-5)
Show solution after attempting 
def my_cosine_sim(A, B, eps=1e-8):
    # Normalize each row to unit length
    A_norm = A / A.norm(dim=-1, keepdim=True).clamp(min=eps)
    B_norm = B / B.norm(dim=-1, keepdim=True).clamp(min=eps)
    return A_norm @ B_norm.T                    # (N, M)

Prompt 4 10 min
Implement sinusoidal positional encoding: sinusoidal_pe(T, D).

Requirements:
• Return: (T, D) positional encoding matrix
• Even indices: sin(pos / 10000^(2i/D))
• Odd indices: cos(pos / 10000^(2i/D))
• No loops. Use broadcasting and torch.arange.

What you need to know

  • pos is a column vector (T, 1). div_term is a row vector (1, D//2). Broadcasting gives you (T, D//2).
  • div_term = exp(-arange(0, D, 2) * log(10000) / D) — compute in log space to avoid huge numbers.
  • Stack sin and cos, then interleave or concatenate.
Show solution after attempting 
def sinusoidal_pe(T, D):
    pos = torch.arange(T).unsqueeze(1).float()      # (T, 1)
    div = torch.exp(
        torch.arange(0, D, 2).float() * (-torch.log(torch.tensor(10000.0)) / D)
    )                                                  # (D//2,)
    angles = pos * div                                 # (T, D//2)

    pe = torch.zeros(T, D)
    pe[:, 0::2] = torch.sin(angles)                  # even indices
    pe[:, 1::2] = torch.cos(angles)                  # odd indices
    return pe


pe = sinusoidal_pe(128, 64)
print(f"PE shape: {pe.shape}")          # (128, 64)
print(f"Row 0 norm: {pe[0].norm():.3f}") # should be ~sqrt(D/2)

Session 4: Flow Matching ~60 min

Understanding conditional flow matching — the loss behind modern TTS like CosyVoice and generative models.

Prompt 5 15 min
Implement the conditional flow matching training step.

Setup: A simple MLP "velocity network" v_net(x_t, t) that predicts the velocity field.

Requirements:
• Sample noise x_0 ~ N(0, I) and target x_1 from your data
• Sample t ~ Uniform(0, 1) for each batch element: shape (B, 1)
• Interpolate: x_t = (1 - t) * x_0 + t * x_1
• Ground truth velocity: v_gt = x_1 - x_0 (optimal transport path)
• Prediction: v_pred = model(x_t, t)
• Loss: MSE(v_pred, v_gt)
• Implement both the model and one training step.

What you need to know

  • Flow matching learns a velocity field that pushes noise → data along a straight OT path.
  • The interpolation x_t = (1-t)*x_0 + t*x_1 defines the path. t=0 is noise, t=1 is data.
  • The network only needs to predict x_1 - x_0 (the displacement). Simpler than diffusion's noise prediction.
  • Conditioning on t: concat it, add it, or use it to modulate. Simplest: concat.
x_0 (noise) ────────────────────▶ x_1 (data) · · · x_t = (1-t)*x_0 + t*x_1 · · ↑ · · model predicts · · v = x_1 - x_0 · · (constant along path) ·
Show solution after attempting 
class VelocityNet(nn.Module):
    """Simple MLP that predicts velocity given (x_t, t)."""
    def __init__(self, d_data, d_hidden=256):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(d_data + 1, d_hidden),   # +1 for t
            nn.SiLU(),
            nn.Linear(d_hidden, d_hidden),
            nn.SiLU(),
            nn.Linear(d_hidden, d_data),
        )

    def forward(self, x_t, t):
        # x_t: (B, D), t: (B, 1)
        return self.net(torch.cat([x_t, t], dim=-1))


# --- One training step ---
d_data = 64
model = VelocityNet(d_data)
optimizer = torch.optim.Adam(model.parameters(), lr=1e-3)

# Fake data: 2D Gaussian mixture
x_1 = torch.randn(32, d_data)                     # target data

optimizer.zero_grad()

# 1. Sample noise and time
x_0 = torch.randn_like(x_1)                          # (B, D)
t = torch.rand(32, 1)                                # (B, 1)

# 2. Interpolate along OT path
x_t = (1 - t) * x_0 + t * x_1                       # (B, D)

# 3. Ground truth velocity
v_gt = x_1 - x_0                                     # (B, D)

# 4. Predict
v_pred = model(x_t, t)                                # (B, D)

# 5. Loss + backward
loss = F.mse_loss(v_pred, v_gt)
loss.backward()
optimizer.step()

print(f"loss: {loss.item():.4f}")
Prompt 6 12 min
Implement flow matching inference (ODE integration) using Euler method.

Requirements:
• Start from x_0 ~ N(0, I)
• Take N Euler steps from t=0 to t=1
• Each step: x_{t+dt} = x_t + dt * v_net(x_t, t)
• Return the final x_1 (generated sample)
• No gradients needed — wrap in torch.no_grad()

What you need to know

  • Euler method: simplest ODE solver. Step size dt = 1/N.
  • More steps = better quality but slower. Typical: 10-100 steps for good generation.
  • @torch.no_grad() — inference doesn't need gradients. Saves memory.
  • The time input to the model must be (B, 1) — use torch.full((B, 1), t_val).
Show solution after attempting 
@torch.no_grad()
def euler_sample(model, shape, n_steps=50):
    """Generate samples by integrating the learned velocity field."""
    B = shape[0]
    dt = 1.0 / n_steps
    x = torch.randn(shape)                            # x_0 ~ N(0, I)

    for i in range(n_steps):
        t_val = i * dt
        t = torch.full((B, 1), t_val)               # (B, 1)
        v = model(x, t)                                # predicted velocity
        x = x + dt * v                                 # Euler step

    return x                                           # x_1 ≈ generated data


# Generate
samples = euler_sample(model, shape=(16, d_data), n_steps=50)
print(f"Generated shape: {samples.shape}")  # (16, 64)

Implement gradient clipping from scratch: my_clip_grad_norm_(parameters, max_norm).

Requirements:
• Compute the global L2 norm of all gradients concatenated
• If total norm > max_norm, scale all grads down by max_norm / total_norm
• Modify gradients in-place
• Return the total norm (before clipping)
• Verify against torch.nn.utils.clip_grad_norm_
Show solution after attempting 
def my_clip_grad_norm_(parameters, max_norm):
    # 1. Compute total L2 norm of all grads
    params = [p for p in parameters if p.grad is not None]
    total_norm = torch.sqrt(
        sum(p.grad.data.norm() ** 2 for p in params)
    )

    # 2. Scale down if needed
    clip_coef = max_norm / (total_norm + 1e-6)
    if clip_coef < 1.0:
        for p in params:
            p.grad.data.mul_(clip_coef)

    return total_norm
