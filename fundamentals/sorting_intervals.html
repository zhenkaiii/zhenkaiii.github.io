Sorting, Intervals & Merging

Scholar LinkedIn CV

Mental model: same as heap, just explicit

Just like heap, the fundamental data structure is a plain list. Each element is a tuple (or list) like [start, end]. The difference from heap:

HeapSorting
Sort key Implicit — Python compares tuples element by element automatically Explicit — you specify key=lambda x: ...
Example heappush(h, (freq, word)) — sorts by freq, then word intervals.sort(key=lambda x: x[0]) — sort by start
Default First element of tuple First element of tuple (so .sort() with no key works for intervals!)

intervals.sort() with no key already sorts by start time. You only need key=lambda when you want a non-default order (e.g., sort by end time).

Custom sort key cheat sheet

# Sort by start time (default — no key needed)
intervals.sort()                              # [[1,5],[2,3],[4,6]]

# Sort by end time (for greedy non-overlapping selection)
intervals.sort(key=lambda x: x[1])           # [[2,3],[1,5],[4,6]]

# Sort by multiple criteria: primary ascending, secondary descending
tasks.sort(key=lambda x: (x[0], -x[1]))

# Sort strings by length, then lexicographically
words.sort(key=lambda w: (len(w), w))

Problem 1: Merge Intervals (LC 56)

Problem: Given a list of intervals [start, end], merge all overlapping intervals and return the non-overlapping result.
Pattern: Sort by start. Linear scan: extend or start new.
Example: [[1,3],[2,6],[8,10],[15,18]] → [[1,6],[8,10],[15,18]]
Scenario: Consolidate overlapping calendar blocks into contiguous free/busy slots.
Time: O(n log n)   Space: O(n) 
def merge(intervals):
    intervals.sort()                     # sort by start (default)
    merged = [intervals[0]]

    for start, end in intervals[1:]:
        if start <= merged[-1][1]:       # overlap: current start ≤ prev end
            merged[-1][1] = max(merged[-1][1], end)   # extend
        else:
            merged.append([start, end])  # gap — new interval

    return merged

Trace: [[1,3],[2,6],[8,10],[15,18]]

After sort: [[1,3],[2,6],[8,10],[15,18]]   (already sorted)
merged = [[1,3]]

[2,6]:   2 ≤ 3? yes → extend end to max(3,6)=6.    merged=[[1,6]]
[8,10]:  8 ≤ 6? no  → new interval.                merged=[[1,6],[8,10]]
[15,18]: 15 ≤ 10? no → new interval.                merged=[[1,6],[8,10],[15,18]] ✓

Problem 2: Insert Interval (LC 57)

Problem: Given a sorted list of non-overlapping intervals and a new interval, insert it and merge if necessary. Return the result still sorted and non-overlapping.
Pattern: Three-phase linear scan: before, overlap, after.
Example: [[1,2],[3,5],[6,7],[8,10],[12,16]], new=[4,8] → [[1,2],[3,10],[12,16]]
Scenario: Add a new meeting to an already-clean calendar.
Time: O(n)   Space: O(n) 
def insert(intervals, new):
    result = []
    i = 0
    n = len(intervals)

    # Phase 1: everything ending before new starts — keep as-is
    while i < n and intervals[i][1] < new[0]:
        result.append(intervals[i])
        i += 1

    # Phase 2: everything overlapping with new — merge into new
    while i < n and intervals[i][0] <= new[1]:
        new[0] = min(new[0], intervals[i][0])
        new[1] = max(new[1], intervals[i][1])
        i += 1
    result.append(new)

    # Phase 3: everything after — keep as-is
    while i < n:
        result.append(intervals[i])
        i += 1

    return result

Problem 3: Non-overlapping Intervals (LC 435)

Problem: Given a list of intervals, find the minimum number of intervals to remove so the rest don't overlap.
Pattern: Sort by end time. Greedily keep earliest-ending non-conflicting interval.
Example: [[1,2],[2,3],[3,4],[1,3]] → remove 1 interval
Scenario: One projector, 10 presentation requests — max you can fit without overlap.
Time: O(n log n)   Space: O(1)

Why sort by end, not start? Finishing earliest leaves the most room for future intervals.

def eraseOverlapIntervals(intervals):
    intervals.sort(key=lambda x: x[1])    # sort by END time
    removed = 0
    prev_end = float('-inf')

    for start, end in intervals:
        if start >= prev_end:             # no conflict — keep it
            prev_end = end
        else:
            removed += 1                  # conflict — skip (remove)

    return removed

After sort by end: [[1,2],[2,3],[1,3],[3,4]]

[1,2]: 1 ≥ -inf? yes → keep.  prev_end=2.  removed=0
[2,3]: 2 ≥ 2? yes   → keep.  prev_end=3.  removed=0
[1,3]: 1 ≥ 3? no    → skip.                removed=1
[3,4]: 3 ≥ 3? yes   → keep.  prev_end=4.  removed=1 ✓

Problem 4: Meeting Rooms II (LC 253)

Problem: Given a list of meeting time intervals [start, end], find the minimum number of conference rooms needed so no two overlapping meetings share a room.
Pattern: Sort by start. Min-heap tracks end times of active rooms.
Example: [[0,30],[5,10],[15,20]] → 2 rooms
Scenario: How many conference rooms does the office need to avoid any conflict?
Time: O(n log n)   Space: O(n) 
import heapq

def minMeetingRooms(intervals):
    intervals.sort(key=lambda x: x[0])     # sort by start
    rooms = []                              # min-heap of end times

    for start, end in intervals:
        if rooms and rooms[0] <= start:     # earliest room is free?
            heapq.heappop(rooms)            # free the room
            heapq.heappush(rooms, end)      # reuse it
        else:
            heapq.heappush(rooms, end)      # need a new room

    return len(rooms)

Trace: [[0,30],[5,10],[15,20]]

[0,30]:  rooms=[] empty     → push 30.          rooms=[30]      1 room
[5,10]:  rooms[0]=30 > 5   → no free → push 10. rooms=[10,30]   2 rooms
[15,20]: rooms[0]=10 ≤ 15 → free! pop+push 20.  rooms=[20,30]   2 rooms (reused)
return len(rooms) = 2 ✓

Why does a heap show up with no "K-th largest" trigger? Because you're repeatedly asking "which room frees up earliest?" — that's a min question. Heap = repeatedly need the min or max of something.

Pattern summary

ProblemSort byWhy this orderCore move
Merge Intervals Start Process left-to-right Extend or start new
Insert Interval (pre-sorted) — Three-phase: before / merge / after
Non-overlapping Intervals End Finish earliest → leave most room for future Greedy — keep if no conflict
Meeting Rooms II Start Process arrivals in order Min-heap of end times — reuse or allocate

Start or end? Sort by start when processing arrivals left-to-right. Sort by end when greedy picking — finish earliest, leave the most room.
