RVQ Speech/Audio Codec

SoundStream / EnCodec Fundamental

The Lineage

AE (foundation)
├── VAE (2013) — continuous latent, sample from Gaussian, KL + reconstruction loss
│   └── VQ-VAE (2017) — replace Gaussian with discrete codebook, drop KL
│       └── SoundStream (2021) — multi-level codebook (RVQ) + GAN discriminator losses
│           └── EnCodec, DAC (2022-23) — same recipe, minor improvements
│
├── GAN (2014) — sharp outputs via adversarial training, no encoder
│   └── HiFi-GAN (2020) — best vocoder, discriminator reused in all codecs above

Modern neural audio codec = AE backbone + RVQ bottleneck + GAN losses. VAE contributed the idea that the bottleneck should have structure. GAN contributed the discriminator for perceptual quality. Neither survived in pure form.

Scalar Quantization vs Vector Quantization

Scalar (what I did in my PhD): Each of the D features gets its own bin index independently. D=128 means 128 indices per frame.

Vector: The entire D-dimensional vector gets one index. One codebook lookup replaces 128 independent lookups.

Scalar: (B, 75, 128) → 128 indices per frame
VQ:     (B, 75, 128) → 1 index per frame
RVQ:    (B, 75, 128) → Q indices per frame (e.g. 8)

Same bottleneck, 16x fewer indices with 8-level RVQ vs scalar. The gist: you don't transmit the features, you only transmit the codebook indices. Those indices are token IDs in today's LLM pipelines.

Bitrate Math

Two chains of math:

# Chain 1: frame rate
sample_rate / receptive_field = frame_rate
24000 / 320 = 75 fps

# Chain 2: bitrate
log2(codebook_size) × num_rvq_levels × frame_rate = bitrate
10 bits × 8 levels × 75 fps = 6000 bps = 6 kbps

Raw 24kHz 16-bit audio = 384 kbps. So 6 kbps = 64x compression.

Two knobs: number of RVQ levels (quality vs compression) and codebook size (bits per level). Frame rate is fixed by encoder architecture.

The Pipeline

(B, 1, 24000)  →  (B, 75, 128)  →  (B, 75, 8)
  waveform          encoder          RVQ indices

# 320 samples → 1 vector of dim 128 → 8 codebook indices
# 1 second of 24kHz audio → 75 frames → 600 integers → 6 kbps

Encoder (SoundStream-style)

Fully convolutional. No frame-by-frame feeding. Strides 2 × 4 × 5 × 8 = 320x downsampling.

Standard encoder design pattern: Channels go up as time goes down. You trade temporal resolution for feature richness. Early layers capture simple patterns (waveform edges) with few channels. Deeper layers capture complex patterns (phonemes, timbre) with many channels over a compressed time axis. Strides also increase deeper in the network — early layers use small strides (2, 4) because the signal is still raw; later layers use bigger strides (5, 8) because the representation is already abstract. Same pattern in ResNet, U-Net, WaveNet encoders. 
class SoundStreamEncoder(nn.Module):
    def __init__(self, dim=128):
        super().__init__()
        # Input: (B, 1, T) raw waveform
        # Strides: 2, 4, 5, 8 → total 320x downsampling
        self.net = nn.Sequential(
            nn.Conv1d(1, dim // 8, kernel_size=7, padding=3),

            nn.Conv1d(dim // 8, dim // 4, kernel_size=4, stride=2, padding=1),
            nn.SiLU(),

            nn.Conv1d(dim // 4, dim // 2, kernel_size=8, stride=4, padding=2),
            nn.SiLU(),

            nn.Conv1d(dim // 2, dim, kernel_size=10, stride=5, padding=3),
            nn.SiLU(),

            nn.Conv1d(dim, dim, kernel_size=16, stride=8, padding=4),
            nn.SiLU(),
        )

    def forward(self, x):
        """x: (B, 1, T) → (B, T//320, 128)"""
        return self.net(x).transpose(1, 2)

RVQ Quantizer

Each level quantizes the residual error from the previous level. Coarse to fine.

class RVQ(nn.Module):
    def __init__(self, num_quantizers, codebook_size, dim):
        super().__init__()
        self.num_quantizers = num_quantizers
        self.codebooks = nn.ParameterList([
            nn.Parameter(torch.randn(codebook_size, dim))
            for _ in range(num_quantizers)
        ])

    def forward(self, x):
        """x: (B, T, D) → quantized (B, T, D), indices (B, T, Q)"""
        residual = x
        quantized = torch.zeros_like(x)
        all_indices = []

        for i in range(self.num_quantizers):
            # distance to each codebook entry
            dist = torch.cdist(residual, self.codebooks[i].unsqueeze(0))
            indices = dist.argmin(dim=-1)        # (B, T)
            all_indices.append(indices)

            z_q = self.codebooks[i][indices]      # (B, T, D)

            # straight-through: forward = z_q, backward = gradient to residual
            z_q_st = residual + (z_q - residual).detach()

            quantized = quantized + z_q_st
            residual = residual - z_q.detach()    # next level encodes the leftover

        indices = torch.stack(all_indices, dim=-1) # (B, T, Q)
        return quantized, indices
Straight-through estimator: z_q_st = residual + (z_q - residual).detach(). Forward pass this equals z_q. Backward pass gradient flows to residual, skipping the non-differentiable argmin. This is the VQ equivalent of the soft-to-hard annealing trick from scalar quantization.

RVQ Intuition

# Level 1: coarse approximation
z1 = codebook_1[nearest(x)]
residual_1 = x - z1

# Level 2: encode what level 1 missed
z2 = codebook_2[nearest(residual_1)]
residual_2 = residual_1 - z2

# Level 3: encode what level 2 missed
z3 = codebook_3[nearest(residual_2)]

# Reconstruction = sum of all levels
x_hat = z1 + z2 + z3

Each level captures finer detail. Like JPEG progressive loading but for audio vectors.

Key Insights

#Insight
1No frame-by-frame feeding. Encoder is fully convolutional, takes whole waveform. What matters is receptive field (320 samples), not frame size.
2320 samples → 1 vector of 128-D. That vector gets quantized, not the raw samples.
3You don't transmit features. You transmit codebook indices. Those indices = token IDs for downstream LLMs.
4Scalar quantization: 128 indices per frame. RVQ with 8 levels: 8 indices per frame. 16x fewer.
5Bitrate = log2(K) × Q × frame_rate. Two knobs: codebook size K and number of RVQ levels Q.
6Straight-through estimator handles the non-differentiable argmin. Same problem as soft-to-hard annealing, different solution.
