heapq Basics

Python's heapq implements a min-heap on a plain list. There is no max-heap — negate values to simulate one. 

import heapq

h = []
heapq.heappush(h, 5)
heapq.heappush(h, 2)
heapq.heappush(h, 8)

heapq.heappop(h)     # 2  (smallest)
h[0]                  # 5  (peek without popping)
Operation Time
heappush O(log n)
heappop O(log n)
heapify O(n)
heapreplace (pop + push) O(log n)
peek (h[0]) O(1)

Pattern 1: Top-K Elements

To find the k largest elements, maintain a min-heap of size k. When the heap exceeds size k, pop the smallest — what remains are the k largest. 

def top_k_largest(nums, k):
    heap = []
    for x in nums:
        heapq.heappush(heap, x)
        if len(heap) > k:
            heapq.heappop(heap)    # evict smallest
    return sorted(heap, reverse=True)

Why min-heap for k largest? The heap acts as a gatekeeper: anything smaller than the current minimum of the top-k gets rejected. This is O(n log k), better than sorting O(n log n) when k « n.

For k smallest, use a max-heap (negate values) of size k, or simply use heapq.nsmallest(k, nums).

Pattern 2: Merge K Sorted Lists

Push the head of each list into a min-heap. Pop the smallest, then push its successor. The heap always holds at most k elements. 

def merge_k_sorted(lists):
    heap = []
    for i, lst in enumerate(lists):
        if lst:
            heapq.heappush(heap, (lst[0], i, 0))  # (value, list_idx, elem_idx)

    result = []
    while heap:
        val, li, ei = heapq.heappop(heap)
        result.append(val)
        if ei + 1 < len(lists[li]):
            heapq.heappush(heap, (lists[li][ei + 1], li, ei + 1))

    return result

Time: O(N log k) where N is total elements across all lists. This same pattern applies to merging k sorted linked lists — just push (node.val, id, node).

Pattern 3: Two-Heap Median

Maintain two heaps to track the median of a data stream:

  • max-heap (lo): stores the smaller half (negate for max-heap behavior)
  • min-heap (hi): stores the larger half

Invariant: len(lo) == len(hi) or len(lo) == len(hi) + 1. The median is -lo[0] (odd count) or (-lo[0] + hi[0]) / 2 (even count). 

class MedianFinder:
    def __init__(self):
        self.lo = []   # max-heap (negated)
        self.hi = []   # min-heap

    def add_num(self, num):
        heapq.heappush(self.lo, -num)
        # ensure max of lo <= min of hi
        heapq.heappush(self.hi, -heapq.heappop(self.lo))
        # balance sizes: lo should be >= hi in size
        if len(self.lo) < len(self.hi):
            heapq.heappush(self.lo, -heapq.heappop(self.hi))

    def find_median(self):
        if len(self.lo) > len(self.hi):
            return -self.lo[0]
        return (-self.lo[0] + self.hi[0]) / 2

Pattern 4: Lazy Deletion

Python's heapq doesn't support removing arbitrary elements. Workaround: mark elements as deleted and skip them when popping. 

# Conceptual pattern
removed = set()

def lazy_pop(heap):
    while heap:
        val = heapq.heappop(heap)
        if val not in removed:
            return val
    raise IndexError("empty heap")

def lazy_remove(heap, val):
    removed.add(val)

This is useful in problems like "sliding window maximum" with a heap approach, where elements leave the window but may still sit in the heap.

heapq Convenience Functions

heapq.nlargest(k, iterable)    # k largest, returns sorted list
heapq.nsmallest(k, iterable)   # k smallest, returns sorted list
heapq.merge(*iterables)        # merge pre-sorted iterables (lazy)

nlargest / nsmallest use a heap internally for small k, and sort for large k. They accept a key parameter.
