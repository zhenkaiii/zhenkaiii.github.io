Speedrun 2: Multi-Head Attention 10 min

Write from scratch — no peeking:

  • MyMHA(d_model, n_head) — full multi-head attention from raw linears
  • Q, K, V projections → reshape → transpose → scaled dot-product → concat → output projection
  • All shapes must be correct: (B,T,D) → (B,H,T,d_k) → (B,T,D)

Target: under 10 minutes. Shape story must be airtight.

Speedrun 3: Loss Functions 8 min

Write from scratch — no peeking:

  • my_softmax(x, dim) — max subtraction, exp, normalize
  • my_cross_entropy(logits, targets) — log-softmax + NLL
  • my_mse_loss(pred, target) — one-liner

Target: all three under 8 minutes total.

Key gotchas to check
  • keepdim=True in softmax for broadcasting
  • Log-softmax: x - max - log(sum(exp(x - max)))
  • NLL pick: log_probs[torch.arange(B), targets]
  • MSE: .mean() over everything — no dim arg
Speedrun 4: LayerNorm + RMSNorm 6 min

Write from scratch — no peeking:

  • MyLayerNorm(d) — mean, var (unbiased=False!), scale + shift
  • MyRMSNorm(d) — no mean centering, just RMS + scale
  • Both as nn.Module with nn.Parameter

Target: both under 6 minutes.

Key gotchas to check
  • nn.Parameter(torch.ones(d)) for weight, torch.zeros(d) for bias
  • var(dim=-1, keepdim=True, unbiased=False) — Bessel's correction off!
  • RMSNorm: (x.pow(2).mean(dim=-1, keepdim=True) + eps).rsqrt()
  • rsqrt() = 1 / sqrt() — faster on GPU, same result
Speedrun 5: GQA Attention 12 min

Write from scratch — no peeking:

  • MyGQA(d_model, n_head, n_kv_heads)
  • K/V projections: d_model → n_kv_heads * d_k (smaller!)
  • repeat_interleave(n_head // n_kv_heads, dim=1) to expand KV heads
  • Rest is same as MHA

Target: under 12 minutes. Repeat count must be right.

Key gotchas to check
  • Init: self.k = nn.Linear(d_model, n_kv_heads * d_k) — not d_model
  • Reshape KV: (B, T, n_kv_heads, d_k) then transpose
  • Repeat: .repeat_interleave(n_head // n_kv_heads, dim=1)
  • Group size = n_head // n_kv_heads, NOT n_kv_heads
  • After repeat, KV has shape (B, n_head, T, d_k) — same as Q
  • Output reshape uses D = n_head * d_k = d_model

Interview Mental Model

What Claudia is likely testing

  • Can you write correct PyTorch from scratch? — nn.Module, forward, training loop
  • Do you understand shapes? — "What shape is this tensor after this operation?"
  • Do you know the gotchas? — batch_first, keepdim, unbiased, three MHA args
  • Can you debug? — "Why is the loss not decreasing?" "Why shape mismatch?"
  • Do you know the ecosystem? — AMP, grad clipping, DataLoader basics

When stuck during interview

  • Say the shapes out loud. "This is (B, T, D), I need (B, H, T, d_k), so I reshape then transpose."
  • Write the signature first. def forward(self, x): with a shape comment.
  • Build incrementally. Get one sublayer working before adding the second.
  • Use print debugging. print(x.shape) is completely acceptable in an interview.
  • Don't panic about syntax. If you forget the exact API, describe what you need: "I need a function that picks elements along dim=1 using these indices" → that's gather.
