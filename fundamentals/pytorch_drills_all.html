Wednesday — Session 1: Loss Functions from Scratch ~90 min

Rules: no F.softmax, no F.cross_entropy, no F.mse_loss. Pure tensor ops. Verify each by comparing against PyTorch's built-in.

Prompt 1 5 min
Implement my_softmax(x, dim) that works on any tensor shape.

Requirements:
• Must handle numerical stability (subtract max before exp)
• Must work for any dim argument
• Verify: torch.allclose(my_softmax(x, dim=-1), F.softmax(x, dim=-1))

What you need to know

  • Naive softmax blows up. exp(1000) = inf. Subtracting max doesn't change the result but prevents overflow.
  • keepdim=True is critical for broadcasting — the max/sum must stay the same rank as x.
  • dim tells softmax which axis the probabilities should sum to 1 across.
Show solution after attempting 
def my_softmax(x, dim=-1):
    # 1. Subtract max for numerical stability
    x_max = x.max(dim=dim, keepdim=True).values
    x_stable = x - x_max

    # 2. Exp
    e = x_stable.exp()

    # 3. Normalize
    return e / e.sum(dim=dim, keepdim=True)


# Verify
x = torch.randn(4, 8)
assert torch.allclose(my_softmax(x, dim=-1), F.softmax(x, dim=-1))
assert torch.allclose(my_softmax(x, dim=0), F.softmax(x, dim=0))
print("softmax: PASS")
Prompt 2 10 min
Implement my_cross_entropy(logits, targets) for classification.

Requirements:
• logits: (B, C) — raw model output, not softmaxed
• targets: (B,) — integer class labels
• Use log-softmax + NLL. No loops over the batch.
• Return a scalar (mean over batch).
• Verify: torch.allclose(my_cross_entropy(logits, targets), F.cross_entropy(logits, targets))

What you need to know

  • Cross-entropy = log-softmax + NLL. -log(softmax(logits))[target_class]
  • Log-softmax trick: log_softmax = x - max - log(sum(exp(x - max))). More numerically stable than log(softmax(x)).
  • Gather the target class: use torch.gather or advanced indexing log_probs[range(B), targets].
Show solution after attempting 
def my_cross_entropy(logits, targets):
    # logits: (B, C), targets: (B,)
    B, C = logits.shape

    # 1. Log-softmax (stable)
    x_max = logits.max(dim=-1, keepdim=True).values
    log_probs = logits - x_max - (logits - x_max).exp().sum(dim=-1, keepdim=True).log()
    # log_probs: (B, C)

    # 2. Pick the log-prob of the target class (NLL)
    nll = -log_probs[torch.arange(B), targets]    # (B,)

    # 3. Mean over batch
    return nll.mean()


# Verify
logits = torch.randn(8, 5)
targets = torch.randint(0, 5, (8,))
assert torch.allclose(my_cross_entropy(logits, targets), F.cross_entropy(logits, targets))
print("cross_entropy: PASS")

Bonus Prompt 5 min
Implement my_bce_with_logits(logits, targets).

Requirements:
• logits: (B,) — raw model output, not sigmoided
• targets: (B,) — binary labels (0 or 1), float
• Formula: -[y * log(σ(x)) + (1-y) * log(1-σ(x))]
• Use the numerically stable form, not naive sigmoid + log.
• Verify against F.binary_cross_entropy_with_logits

What you need to know

  • Stable BCE: max(x, 0) - x*y + log(1 + exp(-|x|)). Avoids log(0) and exp overflow.
  • This is how PyTorch implements it internally.
Show solution after attempting 
def my_bce_with_logits(logits, targets):
    # Numerically stable: max(x,0) - x*y + log(1 + exp(-|x|))
    return (logits.clamp(min=0) - logits * targets + (1 + (-logits.abs()).exp()).log()).mean()


# Verify
logits = torch.randn(8)
targets = torch.randint(0, 2, (8,)).float()
assert torch.allclose(my_bce_with_logits(logits, targets), F.binary_cross_entropy_with_logits(logits, targets))
print("bce_with_logits: PASS")

Prompt 5 8 min
Implement MyLayerNorm as an nn.Module.

Requirements:
• Input: (B, T, D). Normalize over the last dimension.
• Learnable weight (scale) and bias (shift), both shape (D,)
• Use eps=1e-5 for numerical stability in the denominator.
• Verify against nn.LayerNorm(D): copy the weight/bias, check outputs match.

What you need to know

  • LayerNorm formula: (x - mean) / sqrt(var + eps) * weight + bias
  • Mean and var computed over the last dimension (features), not batch.
  • keepdim=True for broadcasting.
  • weight and bias are nn.Parameter — initialized to ones and zeros.
Show solution after attempting 
class MyLayerNorm(nn.Module):
    def __init__(self, d, eps=1e-5):
        super().__init__()
        self.weight = nn.Parameter(torch.ones(d))
        self.bias = nn.Parameter(torch.zeros(d))
        self.eps = eps

    def forward(self, x):
        # x: (B, T, D) — normalize over last dim
        mean = x.mean(dim=-1, keepdim=True)
        var = x.var(dim=-1, keepdim=True, unbiased=False)
        x_norm = (x - mean) / (var + self.eps).sqrt()
        return x_norm * self.weight + self.bias


# Verify
D = 64
x = torch.randn(4, 8, D)
my_ln = MyLayerNorm(D)
ref_ln = nn.LayerNorm(D)
# Copy weights so they match
my_ln.weight.data = ref_ln.weight.data.clone()
my_ln.bias.data = ref_ln.bias.data.clone()
assert torch.allclose(my_ln(x), ref_ln(x), atol=1e-5)
print("LayerNorm: PASS")
Gotcha: x.var() uses Bessel's correction (unbiased=True) by default. PyTorch's nn.LayerNorm uses unbiased=False. You must match it or the verify will fail.
Prompt 6 5 min
Implement MyRMSNorm as an nn.Module.

Requirements:
• Like LayerNorm but no mean centering, no bias. Only scale.
• RMS(x) = sqrt(mean(x^2))
• Output: x / RMS(x) * weight
• Learnable weight shape (D,), initialized to ones.
Show solution after attempting 
class MyRMSNorm(nn.Module):
    def __init__(self, d, eps=1e-6):
        super().__init__()
        self.weight = nn.Parameter(torch.ones(d))
        self.eps = eps

    def forward(self, x):
        # RMS = sqrt(mean(x^2))
        rms = (x.pow(2).mean(dim=-1, keepdim=True) + self.eps).rsqrt()
        return x * rms * self.weight


# Verify (no built-in to compare — just check output shape and scale)
x = torch.randn(4, 8, 64)
rms = MyRMSNorm(64)
out = rms(x)
assert out.shape == x.shape
# After RMSNorm, RMS of output ≈ 1
out_rms = out.pow(2).mean(dim=-1).sqrt().mean()
print(f"RMSNorm output RMS: {out_rms:.3f} (should be ~1.0)")
print("RMSNorm: PASS")

Wednesday — Session 3: Masking, Gathering & Sampling (from Meta prep) ~90 min

These are real interview patterns. They all drill masking with unsqueeze and gather/arange indexing — your weak spots.

Masking Cheat Sheet

Given scores: (B, T, T) and mask: (B, T) where 1 = valid, 0 = padded:

mask.unsqueeze(1) → (B, 1, T) → column mask "Forbid EVERY query from attending to padded keys" Use: scores.masked_fill(mask.unsqueeze(1) == 0, -inf) mask.unsqueeze(2) → (B, T, 1) → row mask "Zero out entire output rows for padded queries" Use: output * mask.unsqueeze(2)
Column mask kills logits BEFORE softmax. Row mask zeros output AFTER softmax. Don't mix them up.
Prompt 10 15 min
Implement masked_softmax(scores, mask, tau).

Inputs:
• scores: (B, T, T) — unnormalized attention weights
• mask: (B, T) — 1 = valid token, 0 = padded
• tau: float, temperature > 0

Requirements:
• Scale by temperature: scores / tau
• If mask[b, j] == 0, column j must get -inf BEFORE softmax (no probability on padded keys)
• If mask[b, i] == 0, entire output row i must be zero
• Use stable softmax (subtract max). Output shape: (B, T, T).

What you need to know

  • Column mask: mask.unsqueeze(1) → (B, 1, T). Broadcasts across all query rows.
  • masked_fill: x.masked_fill(condition, value) — where condition is True, fill with value. So mask == 0 is the condition.
  • Row mask: mask.unsqueeze(2) → (B, T, 1). Multiply output to zero out padded query rows.
  • Add 1e-10 to denominator to handle all--inf rows.
Show solution after attempting 
def masked_softmax(scores, mask, tau):
    # scores: (B, T, T), mask: (B, T), tau: float

    # 1. Scale
    scaled = scores / tau                                  # (B, T, T)

    # 2. Column mask: invalid keys → -inf
    col_mask = (mask.unsqueeze(1) == 0)                    # (B, 1, T)
    scaled = scaled.masked_fill(col_mask, float('-inf'))

    # 3. Stable softmax
    stable = scaled - scaled.max(-1, keepdim=True).values  # (B, T, T)
    num = torch.exp(stable)
    den = num.sum(-1, keepdim=True) + 1e-10
    out = num / den                                        # (B, T, T)

    # 4. Row mask: invalid queries → zero output
    out = out * mask.unsqueeze(2)                           # (B, T, 1)

    return out
Prompt 11 12 min
Implement masked_seq_ce(logits, targets, mask) — masked sequence-level cross-entropy.

Inputs:
• logits: (B, T, C) — unnormalized scores
• targets: (B, T) — integer class labels
• mask: (B, T) — 1 = valid token, 0 = ignore

Requirements:
• Compute per-token CE using logsumexp - x_correct (no softmax)
• Use gather to pick the target logit
• Final loss: sum(CE * mask) / sum(mask) — average only over valid tokens.
Show solution after attempting 
def masked_seq_ce(logits, targets, mask):
    # logits: (B, T, C), targets: (B, T), mask: (B, T)

    # 1. Stability
    stable = logits - logits.max(dim=-1, keepdim=True).values

    # 2. logsumexp (manual since we already subtracted max)
    lse = torch.log(torch.exp(stable).sum(dim=-1) + 1e-10)   # (B, T)

    # 3. Pick target logit via gather
    right = torch.gather(stable, dim=2, index=targets.unsqueeze(-1)).squeeze(-1)  # (B, T)

    # 4. Per-token CE
    ce = lse - right                                        # (B, T)

    # 5. Masked average
    return (ce * mask).sum() / mask.sum()
Pattern: sum(loss * mask) / sum(mask) — the standard way to average loss over variable-length sequences. You'll use this everywhere in NLP/speech.
Prompt 12 12 min
Implement gathered_embed_proj(emb, ids, proj).

Inputs:
• emb: (B, T, D) — embedding table per batch
• ids: (B, K) — indices to gather from emb
• proj: (D, E) — projection matrix

Goal: For each batch b and index k: out[b, k] = emb[b, ids[b, k]] @ proj
Output: (B, K, E)

Two approaches — implement both:
• A. torch.arange(B).unsqueeze(-1) + advanced indexing
• B. gather with unsqueeze + expand

What you need to know

  • Advanced indexing for 3D: emb[torch.arange(B).unsqueeze(-1), ids, :]
  • torch.arange(B) is (B,). .unsqueeze(-1) makes it (B, 1). With ids as (B, K), they broadcast to select (B, K) entries.
  • Gather for 3D: index must match all dims except gathered one. For dim=1 on (B, T, D), index must be (B, K, D) — expand the last dim.
Show solution after attempting 
def gathered_embed_proj(emb, ids, proj):
    # emb: (B, T, D), ids: (B, K), proj: (D, E)
    B, T, D = emb.shape

    # --- Approach A: arange + advanced indexing ---
    fetched = emb[torch.arange(B).unsqueeze(-1), ids, :]  # (B, K, D)
    #   arange(B).unsqueeze(-1): (B, 1)
    #   ids:                     (B, K)
    #   broadcasts to:           (B, K)  → picks B*K entries

    # --- Approach B: gather ---
    # ids_expanded = ids.unsqueeze(-1).expand(-1, -1, D)  # (B, K, D)
    # fetched = torch.gather(emb, dim=1, index=ids_expanded)  # (B, K, D)

    # Project
    return fetched @ proj                                   # (B, K, E)

Prompt 13 12 min
Implement top_k_sample(logits, k) — top-k sampling for autoregressive generation.

Inputs:
• logits: (B, V) — raw logits over vocabulary
• k: int — number of top candidates

Requirements:
• Keep only top-k logits, set everything else to -inf
• Apply stable softmax to get probabilities
• Sample one token per batch using torch.multinomial
• Return: (B, 1) — sampled token indices
• Hint: topk gives you values and indices. scatter_ puts values back.
Show solution after attempting 
def top_k_sample(logits, k):
    # logits: (B, V)
    vals, idx = logits.topk(k, dim=-1)                # (B, k), (B, k)

    # Create -inf mask, scatter top-k values back
    mask = torch.full_like(logits, float('-inf'))
    mask.scatter_(1, idx, vals)                         # (B, V) with top-k restored

    # Stable softmax
    stable = mask - mask.max(dim=-1, keepdim=True).values
    probs = torch.exp(stable)
    probs = probs / (probs.sum(dim=-1, keepdim=True) + 1e-10)

    # Sample
    return torch.multinomial(probs, 1)                  # (B, 1)
scatter_ pattern: target.scatter_(dim, indices, values) — the reverse of gather. Puts values into target at positions given by indices.

Thursday — Session 3: K-Means from Scratch ~90 min

The goal: implement K-means clustering using only PyTorch tensor ops. No sklearn, no loops over data points. This drills cdist, argmin, scatter/index masking, and in-place accumulation.

Prompt 14 8 min
Implement my_cdist(A, B) that computes pairwise L2 distances.

Requirements:
• A: (N, D), B: (M, D)
• Return: (N, M) where [i, j] = ||A[i] - B[j]||_2
• No loops. Use the expansion trick: ||a-b||^2 = ||a||^2 + ||b||^2 - 2*a.b
• Verify: torch.allclose(my_cdist(A, B), torch.cdist(A, B), atol=1e-4)

What you need to know

  • Expansion trick avoids materializing an (N, M, D) difference tensor.
  • ||a||^2 = (A ** 2).sum(dim=-1), keep shape for broadcasting.
  • Cross-term: A @ B.T gives (N, M).
  • .clamp(min=0) before .sqrt() — floating point can give tiny negatives.
Show solution after attempting 
def my_cdist(A, B):
    # A: (N, D), B: (M, D) → (N, M)
    a_sq = (A ** 2).sum(dim=-1, keepdim=True)   # (N, 1)
    b_sq = (B ** 2).sum(dim=-1, keepdim=True)   # (M, 1)
    cross = A @ B.T                               # (N, M)
    dist_sq = a_sq + b_sq.T - 2 * cross           # (N, M)
    return dist_sq.clamp(min=0).sqrt()


# Verify
A = torch.randn(100, 64)
B = torch.randn(10, 64)
assert torch.allclose(my_cdist(A, B), torch.cdist(A, B), atol=1e-4)
print("cdist: PASS")
Prompt 15 20 min
Implement K-means clustering: kmeans(data, K, n_iter=20).

Requirements:
• data: (N, D)
• Initialize centroids by randomly picking K data points (no randperm — use torch.randint or randperm, your choice)
• Each iteration: (1) assign each point to nearest centroid, (2) recompute centroids as mean of assigned points
• No loops over data points — only loop over iterations.
• Use torch.cdist (or your my_cdist) for distances.
• Return: (centroids, assignments) — centroids (K, D), assignments (N,)

What you need to know

  • Assign step: dists = torch.cdist(data, centroids) → (N, K), then assignments = dists.argmin(dim=1).
  • Update step: For each cluster k, new centroid = mean of all points assigned to k.
  • The tricky part: computing cluster means without a for-loop over K. Two options:
    • scatter_add + count: accumulate sums per cluster, then divide.
    • Boolean mask per cluster: data[assignments == k].mean(0) — this loops over K (simpler, acceptable for interview).
Show solution after attempting 
def kmeans(data, K, n_iter=20):
    N, D = data.shape

    # Initialize: pick K random data points
    idx = torch.randperm(N)[:K]
    centroids = data[idx].clone()                  # (K, D)

    for i in range(n_iter):
        # 1. Assign: nearest centroid for each point
        dists = torch.cdist(data, centroids)       # (N, K)
        assignments = dists.argmin(dim=1)          # (N,)

        # 2. Update: mean of each cluster
        new_centroids = torch.zeros_like(centroids)
        for k in range(K):
            mask = assignments == k
            if mask.sum() > 0:
                new_centroids[k] = data[mask].mean(dim=0)
            else:
                new_centroids[k] = centroids[k]    # keep dead centroid
        centroids = new_centroids

    return centroids, assignments

# Fully vectorized update (advanced — bonus points in interview)
def kmeans_vectorized(data, K, n_iter=20):
    N, D = data.shape
    idx = torch.randperm(N)[:K]
    centroids = data[idx].clone()

    for _ in range(n_iter):
        dists = torch.cdist(data, centroids)
        assignments = dists.argmin(dim=1)            # (N,)

        # scatter_add: sum all points per cluster
        sums = torch.zeros(K, D)
        sums.scatter_add_(0, assignments.unsqueeze(1).expand(-1, D), data)
        counts = torch.zeros(K)
        counts.scatter_add_(0, assignments, torch.ones(N))

        # Avoid division by zero for empty clusters
        mask = counts > 0
        centroids[mask] = sums[mask] / counts[mask].unsqueeze(1)

    return centroids, assignments

def my_cosine_sim(A, B, eps=1e-8):
    # Normalize each row to unit length
    A_norm = A / A.norm(dim=-1, keepdim=True).clamp(min=eps)
    B_norm = B / B.norm(dim=-1, keepdim=True).clamp(min=eps)
    return A_norm @ B_norm.T                    # (N, M)

Implement sinusoidal positional encoding: sinusoidal_pe(T, D).

Requirements:
• Return: (T, D) positional encoding matrix
• Even indices: sin(pos / 10000^(2i/D))
• Odd indices: cos(pos / 10000^(2i/D))
• No loops. Use broadcasting and torch.arange.

What you need to know

  • pos is a column vector (T, 1). div_term is a row vector (1, D//2). Broadcasting gives you (T, D//2).
  • div_term = exp(-arange(0, D, 2) * log(10000) / D) — compute in log space to avoid huge numbers.
  • Stack sin and cos, then interleave or concatenate.
Show solution after attempting 
def sinusoidal_pe(T, D):
    pos = torch.arange(T).unsqueeze(1).float()      # (T, 1)
    div = torch.exp(
        torch.arange(0, D, 2).float() * (-torch.log(torch.tensor(10000.0)) / D)
    )                                                  # (D//2,)
    angles = pos * div                                 # (T, D//2)

    pe = torch.zeros(T, D)
    pe[:, 0::2] = torch.sin(angles)                  # even indices
    pe[:, 1::2] = torch.cos(angles)                  # odd indices
    return pe

Prompt 18 15 min
Implement the conditional flow matching training step.

Setup: A simple MLP "velocity network" v_net(x_t, t) that predicts the velocity field.

Requirements:
• Sample noise x_0 ~ N(0, I) and target x_1 from your data
• Sample t ~ Uniform(0, 1) for each batch element: shape (B, 1)
• Interpolate: x_t = (1 - t) * x_0 + t * x_1
• Ground truth velocity: v_gt = x_1 - x_0 (optimal transport path)
• Prediction: v_pred = model(x_t, t)
• Loss: MSE(v_pred, v_gt)
• Implement both the model and one training step.

What you need to know

  • Flow matching learns a velocity field that pushes noise → data along a straight OT path.
  • The interpolation x_t = (1-t)*x_0 + t*x_1 defines the path. t=0 is noise, t=1 is data.
  • The network only needs to predict x_1 - x_0 (the displacement). Simpler than diffusion's noise prediction.
  • Conditioning on t: concat it, add it, or use it to modulate. Simplest: concat.
x_0 (noise) ────────────────────▶ x_1 (data) · · · x_t = (1-t)*x_0 + t*x_1 · · ↑ · · model predicts · · v = x_1 - x_0 · · (constant along path) ·
Show solution after attempting 
class VelocityNet(nn.Module):
    """Simple MLP that predicts velocity given (x_t, t)."""
    def __init__(self, d_data, d_hidden=256):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(d_data + 1, d_hidden),   # +1 for t
            nn.SiLU(),
            nn.Linear(d_hidden, d_hidden),
            nn.SiLU(),
            nn.Linear(d_hidden, d_data),
        )

    def forward(self, x_t, t):
        # x_t: (B, D), t: (B, 1)
        return self.net(torch.cat([x_t, t], dim=-1))

Prompt 19 12 min
Implement flow matching inference (ODE integration) using Euler method.

Requirements:
• Start from x_0 ~ N(0, I)
• Take N Euler steps from t=0 to t=1
• Each step: x_{t+dt} = x_t + dt * v_net(x_t, t)
• Return the final x_1 (generated sample)
• No gradients needed — wrap in torch.no_grad()

What you need to know

  • Euler method: simplest ODE solver. Step size dt = 1/N.
  • More steps = better quality but slower. Typical: 10-100 steps for good generation.
  • @torch.no_grad() — inference doesn't need gradients. Saves memory.
  • The time input to the model must be (B, 1) — use torch.full((B, 1), t_val).
Show solution after attempting 
@torch.no_grad()
def euler_sample(model, shape, n_steps=50):
    """Generate samples by integrating the learned velocity field."""
    B = shape[0]
    dt = 1.0 / n_steps
    x = torch.randn(shape)                            # x_0 ~ N(0, I)

    for i in range(n_steps):
        t_val = i * dt
        t = torch.full((B, 1), t_val)               # (B, 1)
        v = model(x, t)                                # predicted velocity
        x = x + dt * v                                 # Euler step

    return x                                           # x_1 ≈ generated data


# Generate
samples = euler_sample(model, shape=(16, d_data), n_steps=50)
print(f"Generated shape: {samples.shape}")  # (16, 64)
Prompt 20 15 min
Add mixed precision (AMP) to a training loop.

Requirements:
• Use torch.amp.autocast('cuda') around forward + loss
• Use torch.amp.GradScaler('cuda') for loss scaling
• Correct order: scaler.scale(loss).backward() → scaler.step(optimizer) → scaler.update()
• Add gradient clipping with scaler.unscale_(optimizer) before torch.nn.utils.clip_grad_norm_
• Write a full 20-step loop using the MiniTransformerBlock from Tuesday.

What you need to know

  • AMP = Automatic Mixed Precision. Forward pass runs in FP16 (faster, less memory). Backward stays FP32 where needed.
  • GradScaler prevents FP16 gradients from underflowing to zero. It scales the loss up before backward, then unscales grads before optimizer step.
  • Gradient clipping goes between unscale_ and step. You must unscale first so the clip threshold is in FP32 units.
  • Order: zero_grad → autocast(forward + loss) → scaler.scale(loss).backward() → scaler.unscale_(opt) → clip_grad → scaler.step(opt) → scaler.update()
optimizer.zero_grad() │ ▼ with autocast('cuda'): pred = model(x) ← FP16 forward loss = F.mse_loss(...) ← FP16 loss │ ▼ scaler.scale(loss).backward() ← scaled FP16 grads │ ▼ scaler.unscale_(optimizer) ← back to FP32 grads │ ▼ clip_grad_norm_(...) ← clip in FP32 │ ▼ scaler.step(optimizer) ← update weights (skips if inf/nan) │ ▼ scaler.update() ← adjust scale factor
Show solution after attempting 
# Assumes CUDA is available. On CPU, autocast still works but no speedup.
import torch
import torch.nn as nn
import torch.nn.functional as F


class MiniTransformerBlock(nn.Module):
    def __init__(self, d_model, d_ff, n_head):
        super().__init__()
        self.mha = nn.MultiheadAttention(d_model, n_head, batch_first=True)
        self.mlp = nn.Sequential(
            nn.Linear(d_model, d_ff), nn.SiLU(), nn.Linear(d_ff, d_model),
        )
        self.norm_1 = nn.LayerNorm(d_model)
        self.norm_2 = nn.LayerNorm(d_model)

    def forward(self, x):
        h = self.norm_1(x)
        h, _ = self.mha(h, h, h)
        x = x + h
        h = self.norm_2(x)
        h = self.mlp(h)
        x = x + h
        return x


device = "cuda" if torch.cuda.is_available() else "cpu"

# --- Setup ---
data = torch.randn(32, 128, 512, device=device)
model = MiniTransformerBlock(512, 2048, 8).to(device)
optimizer = torch.optim.Adam(model.parameters(), lr=1e-3)
scaler = torch.amp.GradScaler("cuda")

# --- Training loop with AMP ---
for i in range(20):
    optimizer.zero_grad()

    idx = torch.randint(0, 32, (4,))
    x = data[idx]
    y = x[:, 1:, :]

    # Forward + loss in autocast
    with torch.amp.autocast("cuda"):
        pred = model(x[:, :-1, :])
        loss = F.mse_loss(pred, y)

    # Backward with scaled loss
    scaler.scale(loss).backward()

    # Unscale → clip → step → update
    scaler.unscale_(optimizer)
    torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)
    scaler.step(optimizer)
    scaler.update()

    if i % 5 == 0:
        print(f"step {i:3d} | loss {loss.item():.4f}")
Common mistakes:
• Calling loss.backward() instead of scaler.scale(loss).backward()
• Clipping grads before scaler.unscale_() — clip values would be wrong
• Forgetting scaler.update() at the end — scale factor never adjusts
• Putting optimizer.step() instead of scaler.step(optimizer)

Implement gradient clipping from scratch: my_clip_grad_norm_(parameters, max_norm).

Requirements:
• Compute the global L2 norm of all gradients concatenated
• If total norm > max_norm, scale all grads down by max_norm / total_norm
• Modify gradients in-place
• Return the total norm (before clipping)
• Verify against torch.nn.utils.clip_grad_norm_
Show solution after attempting 
def my_clip_grad_norm_(parameters, max_norm):
    # 1. Compute total L2 norm of all grads
    params = [p for p in parameters if p.grad is not None]
    total_norm = torch.sqrt(
        sum(p.grad.data.norm() ** 2 for p in params)
    )

    # 2. Scale down if needed
    clip_coef = max_norm / (total_norm + 1e-6)
    if clip_coef < 1.0:
        for p in params:
            p.grad.data.mul_(clip_coef)

    return total_norm
